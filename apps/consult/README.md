# apps/consult (Phase 2, not built)

Placeholder for the independent online consultation platform (`consult.royalclinicmedics.ie`): secure doctor login,
video consultations, clinical notes, patient records, certificates, referral letters and patient access to documents.

**Do not build anything here in Phase 1.** Phase 1 is structured so this app can be added later without rebuilding the
website. See `docs/PHASE-2-READINESS.md` for the extension points it will use (events, booking functions, permissions,
patient ids, storage and video interfaces, shared design tokens).
